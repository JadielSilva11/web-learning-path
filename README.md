# Web Development Learning Path

Este repositório reúne meu processo de aprendizado na disciplina de **Desenvolvimento de Software para Web**, abrangendo desde os fundamentos da construção de páginas web até o desenvolvimento de aplicações modernas utilizando React e boas práticas de arquitetura de software.

O objetivo é consolidar conhecimentos em desenvolvimento web, compreender o funcionamento das principais tecnologias do ecossistema front-end e back-end e aplicar conceitos de organização, manutenção e escalabilidade de software.

## 📚 Conteúdos Abordados

### 🔹 HTML (HyperText Markup Language)

* Estrutura básica de páginas web
* Elementos semânticos
* Formulários
* Tabelas
* Listas
* Links e navegação
* Boas práticas de acessibilidade

### 🔹 CSS (Cascading Style Sheets)

* Seletores
* Box Model
* Posicionamento de elementos
* Flexbox
* Grid Layout
* Responsividade
* Animações e transições
* Organização de estilos

### 🔹 JavaScript

* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Funções
* Arrays e objetos
* Manipulação do DOM
* Eventos
* Programação assíncrona
* Consumo de APIs

### 🔹 React

* Componentes
* Props
* State
* Hooks
* Renderização condicional
* Listagem de dados
* Gerenciamento de eventos
* Comunicação entre componentes
* Organização de projetos React

### 🔹 Vite

* Criação de projetos modernos
* Ambiente de desenvolvimento rápido
* Estrutura de projetos React
* Build e empacotamento de aplicações
* Configuração de dependências

### 🔹 Arquitetura e Boas Práticas

* Separação de responsabilidades
* Organização em camadas
* Estruturação de projetos Front-End e Back-End
* Reutilização de componentes
* Modularização de código

### 🔹 Princípios SOLID

* Single Responsibility Principle (SRP)
* Open/Closed Principle (OCP)
* Liskov Substitution Principle (LSP)
* Interface Segregation Principle (ISP)
* Dependency Inversion Principle (DIP)

### 🔹 ORM (Object Relational Mapping)

* Conceitos de mapeamento objeto-relacional
* Entidades e relacionamentos
* Persistência de dados
* Abstração de consultas ao banco de dados
* Integração entre aplicação e banco de dados

## 🎯 Objetivos do Repositório

* Praticar conceitos fundamentais do desenvolvimento web
* Desenvolver aplicações utilizando tecnologias modernas
* Aprender padrões de projeto e boas práticas de programação
* Compreender a integração entre Front-End, Back-End e Banco de Dados
* Construir uma base sólida para projetos web escaláveis e de fácil manutenção

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* React
* Vite
* Node.js
* ORM
* Git e GitHub
